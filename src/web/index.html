    What this is

    A complete hybrid retrieval engine: a hand-written BM25 ranker, a flat cosine index and an HNSW graph over transformer embeddings, reciprocal-rank and linear fusion, an optional cross-encoder rerank stage, and an extractive answer composer that only ever quotes the corpus verbatim.

    What runs where

    Everything runs in this tab, in a Web Worker. The bundled night-sky corpus (50 articles) and its 40-query graded eval set are served with precomputed vectors from bge-small-en-v1.5 (pinned revision), so the demo is instant and its numbers are reproducible - CI regenerates those vectors and fails if they drift. The real model loads on demand, only when you type a custom query or index your own documents. The neural reranker (ms-marco-MiniLM-L-6-v2, raw logits) is a separate on-demand download. Models come from the Hugging Face CDN over HTTPS and are cached by the browser.

    Honest limits

    • The eval set is small (40 queries) and hand-labeled; treat the numbers as a demonstration of method, not a benchmark claim.
    • Hybrid fusion does not win every metric on every corpus - the Eval view shows where dense recall beats fused recall here.
    • Answers are extractive by design: no generative model, no invented text, but also no synthesis beyond quoting.
    • ONNX Runtime runs single-threaded here (GitHub Pages cannot send cross-origin isolation headers), so live embedding is slower than it could be.
    • Your uploaded documents never leave the tab; nothing is logged or sent anywhere.
